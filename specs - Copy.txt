Product Name: MoneyLens

Expense & Split Tracking Web App — Product Specification
1. Product Goal
Build a modern web application that helps users:

Track all personal expenses.
Understand spending patterns by month, year, and category.
Set and monitor spending budgets.
Split expenses with friends.
Track money owed by friends.
Track money the user owes to others.
Send reminders for pending payments.
Mark debts as settled and maintain settlement history.
The application should be simple, fast, mobile-friendly, and easy to use.

Suggested Product Name
TabBack

Tagline:
"Track your spending. Split the bill. Get paid back."

2. Target User
A person who wants a single place to:

Record daily expenses.
Analyse monthly/yearly spending.
Understand where their money goes.
Manage shared expenses with friends.
Remember who owes them money.
Avoid manually calculating balances.

15. Important Business Logic
The system must correctly calculate balances.

Example:

User pays ₹3,000.

Three people owe:

Rahul → ₹1,000
Aman  → ₹1,000
Neha  → ₹1,000

Total receivable:

₹3,000

If Rahul pays ₹1,000:

Rahul → Settled
Aman  → ₹1,000 pending
Neha  → ₹1,000 pending

Total receivable:

₹2,000

The original ₹3,000 expense remains unchanged.

17. UX Principles
The application should be:

Simple
Fast
Mobile-first/responsive
Minimal
Data-focused
Easy to understand
Adding an expense should take less than 10 seconds for a normal transaction.

Avoid complicated financial terminology.

The user should always be able to answer:

"How much did I spend?"

"Where did I spend it?"

"Who owes me money?"

"Whom do I owe?"

"How much have I spent this month/year?"

18. Final Product Goal
Build a personal finance application that combines:

Expense Tracking + Spending Analytics + Expense Splitting + IOU/Settlement Tracking

The key differentiator is the ability to track shared expenses and make sure users don't forget to collect money owed by friends.

The product should feel like a combination of:

Personal expense tracker + spending analytics + lightweight IOU manager

but remain simple enough for everyday use.
