# TabBack — Build Progress

**Product:** TabBack ("Track your spending. Split the bill. Get paid back.")
**Source of truth:** `prd.md` + `issues/` folder (01–11, sequential build order).

## Stack (fixed decisions — do not change without a decision record here)

- Next.js (App Router, TypeScript), Tailwind CSS, Vitest (unit tests). **Charts: pure CSS/SVG, no Recharts** (decision recorded 2026-08-11 in the issue-10 section — deterministic server render, zero client deps, testable pure helpers; issue 10 review allowed the change).
- Supabase: Postgres, Auth (email/password + Google), Storage (private receipts bucket), RLS on every user-scoped table (`auth.uid()`).
- Hosted on Vercel. Single currency ₹, `numeric(12,2)` in DB.
- **Supabase credentials:** placeholders. All agents use `.env.example` + `.env.local` with dummy values; real keys get pasted later by the user. README documents setup.
- **Verification without live Supabase:** unit tests + `npm run build`/lint + dev-server UI checks. RLS/SQL contract verified by tests that assert against the migration SQL files (documented approach).
- Money: `round2` helper at every boundary. ₹ format: `₹` prefix, exactly 2 decimals, Indian grouping (en-IN).
- No code comments unless asked. Mobile-first; bottom tab bar + center FAB on mobile, sidebar on desktop.
- Domain model & splitting semantics: see `prd.md` "Implementation Decisions" — every agent must read it.
